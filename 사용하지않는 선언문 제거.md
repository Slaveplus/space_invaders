# 사용되지 않는 선언 제거 리팩토링

## 개요
src 디렉토리 내 모든 사용되지 않는 선언(import, private 메서드, private 필드, 로컬 변수)을 제거하여 코드 품질을 개선했습니다.

## 2. 사용되지 않는 private 메서드 제거

### 2.1 BaseAlienEntity.java
- **제거 메서드**: `avoidPlayer()`
- **이유**: 어디서도 호출되지 않음

**수정 전**:
```java
private void avoidPlayer() {
    try {
        int playerX = environment.getPlayerShipX();
        int playerY = environment.getPlayerShipY();
        double dxToPlayer = playerX - x;
        double dyToPlayer = playerY - y;
        double distanceToPlayer = Math.sqrt(dxToPlayer * dxToPlayer + dyToPlayer * dyToPlayer);
        double minDistance = 120;
        if (distanceToPlayer < minDistance && distanceToPlayer > 0) {
            double moveAwayX = -dxToPlayer / distanceToPlayer;
            double moveAwayY = -dyToPlayer / distanceToPlayer;
            this.dx = moveAwayX * moveSpeed * 1.5;
            this.dy = moveAwayY * moveSpeed * 0.5;
            movingRight = this.dx > 0;
            movingDown = this.dy > 0;
        }
    } catch (Exception ignore) {
    }
}
```

**수정 후**: 메서드 전체 제거

## 4. 사용되지 않는 로컬 변수 제거

---

## 요약

### 통계
- **제거된 import**: 약 30개
- **제거된 private 메서드**: 5개
- **제거된 private 필드**: 4개
- **제거된 로컬 변수**: 0개

### 개선 효과
1. **코드 가독성 향상**: 불필요한 선언 제거로 코드가 더 명확해짐
2. **컴파일 시간 단축**: 사용되지 않는 import 제거로 컴파일러 부담 감소
3. **유지보수성 향상**: 실제 사용되는 코드만 남아 유지보수가 쉬워짐
4. **린터 경고 감소**: 사용되지 않는 선언 관련 경고 제거

### 주의사항
- 일부 필드(`SideMonster.round`, `ServerGameSession.server`, `ServerGameSession.intermissionStartedAt`, `ServerMultiplayerGame.alienCount`, `ServerMultiplayerGame.currentSpaceshipSkin`)는 린터에서 사용되지 않는다고 표시되지만, 실제로는 코드에서 참조되고 있어 제거하지 않았습니다.
